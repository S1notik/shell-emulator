# Эмулятор оболочки ОС

Практическая работа №1 по дисциплине «Конфигурационное управление», вариант 20.
Этап 1 — REPL.

## 1. Общее описание

Эмулятор командной строки UNIX-подобной операционной системы с графическим
интерфейсом. Приложение написано на Java с использованием Swing и не требует
внешних зависимостей.

Окно состоит из области вывода, имитирующей терминал, и панели ввода с полем
команды и кнопкой отправки. Команда выполняется по нажатию Enter или по клику
на кнопку.

Заголовок окна и приглашение к вводу формируются из реальных данных
операционной системы, в которой запущен эмулятор:

```
Эмулятор - [username@hostname]
username@hostname:~$
```

На текущем этапе команды `ls` и `cd` являются заглушками — они выводят своё имя
и полученные аргументы, но не работают с файловой системой. Работа с виртуальной
файловой системой появится на следующих этапах.

## 2. Описание функций и настроек

### Команды

| Команда | Аргументы | Поведение |
| --- | --- | --- |
| `ls` | любое количество | Выводит своё имя и аргументы |
| `cd` | не более одного | Выводит своё имя и аргумент |
| `exit` | не принимает | Завершает работу эмулятора |

### Разбор аргументов

Парсер разбивает введённую строку на имя команды и список аргументов. Аргумент
может быть заключён в одинарные или двойные кавычки — тогда пробелы внутри него
не считаются разделителями. Сами кавычки являются разметкой и в результат не
попадают. Повторяющиеся пробелы между аргументами игнорируются.

| Ввод | Результат разбора |
| --- | --- |
| `cd docs downloads` | команда `cd`, два аргумента |
| `cd "My Documents"` | команда `cd`, один аргумент `My Documents` |
| `ls 'one two' three` | команда `ls`, аргументы `one two` и `three` |
| `ls    -la` | команда `ls`, один аргумент `-la` |
| `ls ""` | команда `ls`, один пустой аргумент |

### Обработка ошибок

| Ситуация | Сообщение |
| --- | --- |
| Незакрытая кавычка | `Ошибка разбора: Незакрытая кавычка: <строка>` |
| Неизвестная команда | `<имя>: команда не найдена` |
| Лишние аргументы у `cd` | `cd: слишком много аргументов` |
| Аргументы у `exit` | `exit: команда не принимает аргументов` |

Пустой ввод игнорируется без сообщения.

### Настройки

Параметров командной строки на этом этапе нет — они появятся на этапе 2.
Размер окна (800×500) и кегль шрифта (13) заданы константами в классе
`EmulatorFrame`.

## 3. Сборка и запуск

Требуется JDK 21 или новее. Внешних библиотек не нужно.

Сборка выполняется с флагом `--release 21`, поэтому байт-код не зависит от
версии JDK, установленной на машине.

### Linux и macOS

```bash
./run.sh     # сборка и запуск эмулятора
./test.sh    # сборка и запуск тестов
```

Если скрипты не запускаются, выдайте им право на исполнение:

```bash
chmod +x run.sh test.sh
```

### Windows

```bat
run.bat
test.bat
```

### Результат запуска тестов

```
OK   имя команды без аргументов
OK   аргументов нет
...
Все проверки пройдены
```

Тесты проверяют разбор строки: команды с аргументами и без, обе разновидности
кавычек, повторяющиеся пробелы, пустой ввод, пустой аргумент и незакрытую
кавычку. Написаны без внешних библиотек, чтобы запуск требовал только JDK.

## 4. Примеры использования

После запуска открывается окно эмулятора. Пример сессии:

```
Эмулятор запущен. Введите команду.
user@host:~$ ls
ls
user@host:~$ ls -la /home
ls "-la", "/home"
user@host:~$ cd "My Documents"
cd "My Documents"
user@host:~$ ls 'one two' three
ls "one two", "three"
user@host:~$ frobnicate
frobnicate: команда не найдена
user@host:~$ cd docs downloads
cd: слишком много аргументов
user@host:~$ exit abc
exit: команда не принимает аргументов
user@host:~$ cd "unterminated
Ошибка разбора: Незакрытая кавычка: cd "unterminated
user@host:~$ exit
```

Аргументы выводятся в кавычках, чтобы были видны их границы: по выводу
`cd "My Documents"` сразу понятно, что аргумент один, а не два.
